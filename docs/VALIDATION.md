# 交接版验证记录

日期：2026-10-01。软件版本：0.6.0。环境：Windows、Python 3.12.5、全新虚拟环境（未启用 system-site-packages）。

- 从空 `vendor/` 在线获取两份固定上游源码，应用团队补丁；五个修改/新增文件按规范化换行后的 SHA256 校验通过。重复 bootstrap 通过。
- 从锁定的一组依赖安装；框架完整离线测试 **130 项通过**。
- 最终针对个人配置、两个独立课题、分享检查器及上游贡献文件测试 **14 项通过**，其中 **11 项**为上游贡献测试，3 项已计入上述 130 项。
- threshold、linear 两套确定性项目示例完成全部阶段，重启和重复推进不会重新执行已验收任务；模型调用数为 0。
- 两份独立 STALE 合成项目走完实验、替身读者/评审、分析和模型草稿流程。验证附件修改会使所属项目失效，另一个项目保持完成状态；重复项目 ID 被拒绝，数据快照去重生效。
- ICLR 六个样式/模板文件在线下载并核对哈希通过。环境 doctor 能识别固定引擎；模型连接标记为未测试。
- 暂存内容经过文件范围及凭证模式扫描，并额外与队长本机实际 API Key、V4/V5 评审凭证进行不输出值的比对；未发现匹配。

首次测试遇到 Windows 沙箱临时目录权限问题，改为获准的专用目录后运行。干净环境暴露了替身模型后端仍强制读取本地模型配置的问题，已修复为只有真实后端才读取凭证配置。独立运行上游贡献测试所需的 vendor Python 路径已在 pytest 配置中明确设置。

本次没有调用真实模型、重跑真实科研、生成新论文、上传评审或重新提交比赛。合成测试只证明编排、隔离、恢复与审计行为，不能证明新课题有效性或模型兼容性。STALE 完整真实数据下载/科研未在交接测试中重复执行。

仓库提供 Windows/Ubuntu 的 GitHub Actions 工作流；远端实际结果以 Actions 页面为准，不将本地 Windows 验证写成已完成 Linux 验证。
